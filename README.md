# SWYNEX Final Data Analytics Project

## Project Overview
This project demonstrates a complete Data Analytics workflow using Python.

The project includes:
- Raw data collection
- Data cleaning
- Exploratory data analysis
- Data visualization
- Dashboard creation

## Dataset
The project uses Titanic passenger data for analysis.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / VS Code
- GitHub

## Project Structure

- `Raw_Data/` – Raw dataset
- `Cleaned_Data/` – Cleaned dataset
- `Analysis/` – Data analysis code
- `Dashboard/` – Dashboard and visualization
- `Screenshots/` – Project screenshots

## Data Cleaning
The dataset was cleaned by:
- Handling missing values
- Removing duplicate records
- Correcting data types
- Preparing data for analysis

## Data Analysis
The analysis includes:
- Passenger survival analysis
- Survival rate by gender
- Survival rate by passenger class
- Passenger distribution by embarked port

## Dashboard
A Titanic Data Analytics Dashboard was created to display:
- Total Passengers
- Total Survivors
- Survival Rate
- Survival Rate by Gender
- Survival Rate by Passenger Class
- Passengers by Embarked Port

## Key Result
The dashboard provides a clear visual summary of passenger survival patterns in the Titanic dataset.
